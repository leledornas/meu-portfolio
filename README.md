## // sobre o projeto

Site de portfólio pessoal desenvolvido do zero com HTML, CSS e JavaScript puro — sem frameworks, sem dependências pesadas. O design prioriza tipografia expressiva, paleta escura com acentos em rosa pastel e amarelo, e animações de entrada suaves.

---

## // páginas

| arquivo | conteúdo |
|---|---|
| `index.html` | Apresentação, habilidades e currículo |
| `projetos.html` | Projetos com links externos |
| `certificados.html` | Certificados por instituição e ano |
| `experiencia.html` | Experiência profissional e formação |
| `contato.html` | Formulário e redes sociais |

---

## // tecnologias

```
HTML5        → estrutura semântica (header, main, section, footer, nav, form)
CSS3         → Flexbox, Grid, variáveis CSS, animações com @keyframes
JavaScript   → cursor personalizado, animações de entrada com requestAnimationFrame
Fira Code    → tipografia mono (Google Fonts)
Playfair     → tipografia display (Google Fonts)
Figtree      → tipografia body (Google Fonts)
Bootstrap Icons → ícones via CDN
```

---

## // critérios atendidos

- [x] **Layout** — uso de Flexbox e CSS Grid em todas as seções
- [x] **Diversidade de componentes** — tags semânticas: `<header>` `<main>` `<section>` `<footer>` `<nav>` `<form>`
- [x] **Navegação** — cinco páginas além do `index.html`
- [x] **JavaScript** — cursor personalizado animado + sistema de animações de entrada com `requestAnimationFrame`
- [x] **Marcação válida** — validado pelo [W3C Markup Validation Service](https://validator.w3.org/)
- [x] **README** — com mais de um commit de atualização
