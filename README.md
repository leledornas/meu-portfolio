# Portfólio — Letícia Dornas
 
Site de portfólio pessoal desenvolvido com HTML, CSS e JavaScript, disponível publicamente no GitHub Pages.
 
🔗 **Acesse:** [leledornas.github.io/meu-portfolio](https://leledornas.github.io/meu-portfolio/)
 
---
 
## Sobre o projeto
 
Este portfólio foi criado para apresentar minha trajetória, projetos, certificados e experiências na área de tecnologia. Sou estudante de Ciência da Computação na CESAR School e busco criar soluções através do código.
 
---
 
## Tecnologias utilizadas
 
- HTML5
- CSS3
- JavaScript
---
 
## Estrutura de páginas
 
| Página | Descrição |
|---|---|
| `index.html` | Apresentação pessoal, tags de habilidades e currículo |
| `projetos.html` | Projetos desenvolvidos com links externos |
| `certificados.html` | Certificados obtidos com instituição e ano |
| `experiencia.html` | Experiência profissional e formação acadêmica |
| `contato.html` | Formulário de contato e links para redes sociais |
 
---
 
## Critérios atendidos
 
- **Layout:** uso de Flexbox e CSS Grid para estruturação de todos os componentes e seções
- **Diversidade de componentes:** uso de tags semânticas como `<header>`, `<main>`, `<section>`, `<footer>`, `<nav>`, `<form>`
- **Navegação:** cinco páginas navegáveis além do `index.html`
- **Recurso em JavaScript:** cursor personalizado animado e sistema de animações de entrada com `requestAnimationFrame`
- **Marcação válida:** HTML validado pelo [W3C Markup Validation Service](https://validator.w3.org/)
- **README:** com mais de um commit de atualização de conteúdo
